# Experiment outputs

The experiment scripts write generated CSV files to this directory.

Expected outputs include:

- `main_benchmarks.csv`
- `ablation.csv`
- `quadrature_diagnostics.csv`
- `regularization.csv`
- `normalization.csv`
- `noise_robustness.csv`
- `feature_ordering.csv`
- `interpretability_stability.csv`
- `scalability.csv`

Run the corresponding script from `experiments/` to generate each file.
