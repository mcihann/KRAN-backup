# Revised manuscript reference tables (verbatim transcription)

These 22 CSVs were extracted from **Manusctrip_r2_v13(3).docx**, the revised manuscript supplied for this repository update. CSV numbering follows **table order**, not every caption's printed numbering (the DOCX repeats “Table 17” for its interpretability-stability table; position 18 is filed as `table_18_*`).

They are **source-table transcriptions**: original units, column order, strings, rounding, dashes, punctuation and errors were retained rather than corrected. They are not raw experiment logs or re-computed metrics. A `mean±SD` claim cannot be numerically verified from a visually ambiguous combined string; some DOCX cells have text like `0.851001`. Consult source and correct source formatting rather than guessing a delimiter.

Tables 4 and 5 are the main repeated comparisons; Tables 7 and 8 are separate fixed-budget ablations; Table 14 describes seven feature orderings; Tables 15–20 describe interpretability analyses; Table 21 is the scalability experiment.
